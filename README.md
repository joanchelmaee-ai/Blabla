Colour is locked fully and brightness at half strength, smoothed over time.

## Look
- **Colour: no filter.** Footage keeps its true, as-filmed colours. There is no colour grade and no added grain; the only colour correction is `wb_lock`, which holds each shot to its own reference frame and cancels the phone's auto white-balance flicker. `wb_lock` has highlight protection: when it lifts a frame the camera auto-darkened (e.g. as she steps close), the lift is capped so the brightest detail (white tops, bright fabric) never clips, and a frame is never darkened. Optional looks remain available per edit (`"grade": "edit/grade.txt"` or `edit/grade_natural.txt`) but are off everywhere.
- **Fonts** (`type/fonts`, all OFL licensed): Pinyon Script for the cursive line, and Montserrat as a stand-in for Gotham on the lowercase line. To use real Gotham, drop the file in and edit its `@font-face` rule in `type/<project>.html`.
- **Audio:** a silent-ready bed (room tone, soft clinks or plug clicks as items appear, airy whooshes on transitions), kept low so a trending sound added in the TikTok app sits on top.

- **Quality (always on):**
  - Phone/WhatsApp footage is low resolution (e.g. 464×832), so every enlarged crop goes through an AI upscaler: Real-ESRGAN compact x4 (`realesr-general-x4v3`), which is trained on real-world degradations including compression.
  - It runs on CPU via onnxruntime. `scripts/build_sr_model.py` builds it from the official weights with a weights-only loader, and does so automatically on first render.
  - A light temporal denoise runs before upscaling so the result stays stable from frame to frame.
  - Export: H.264 High at CRF 14 with `aq-mode=3` (less banding on white walls and desks), bt709, AAC 192k, no added grain. That's roughly 15–20 Mbps, well above what TikTok/Instagram re-encode to.
  - `--draft` skips the upscaler for quick previews.
  - On the glasses reel this raised measured detail 2–3× and lowered frame-to-frame shimmer by about 20%.

## Re-render
```
pip install numpy opencv-python-headless onnx onnxruntime   # plus ffmpeg, node + playwright (chromium)
scripts/render_all.sh                      # every edit, full quality (AI upscaling ~2.5s/frame on CPU)
python3 scripts/render.py bracelets        # -> out/bracelets/final_1080x1920.mp4
python3 scripts/render.py power_strip      # -> out/power_strip/final_1080x1920.mp4
python3 scripts/render.py usb_hub          # -> out/usb_hub/final_1080x1920.mp4
python3 scripts/render.py glasses          # -> out/glasses/final_1080x1920.mp4
python3 scripts/render.py olive_top        # -> out/olive_top/final_1080x1920.mp4
python3 scripts/render.py polka_top_reveal # -> out/polka_top_reveal/final_1080x1920.mp4
python3 scripts/render.py polka_top_angles # -> out/polka_top_angles/final_1080x1920.mp4
python3 scripts/render.py red_top          # -> out/red_top/final_1080x1920.mp4
python3 scripts/render.py green_cami_look  # -> out/green_cami_look/final_1080x1920.mp4
python3 scripts/render.py green_cami_playful # -> out/green_cami_playful/final_1080x1920.mp4
python3 scripts/render.py print_halter     # -> out/print_halter/final_1080x1920.mp4
python3 scripts/render.py black_tee_denim  # -> out/black_tee_denim/final_1080x1920.mp4
python3 scripts/render.py cream_cardigan   # -> out/cream_cardigan/final_1080x1920.mp4
python3 scripts/render.py white_drape_top  # -> out/white_drape_top/final_1080x1920.mp4
```
- `edit/<project>.json`: the timeline (source in/out, speed and ramps (`ramp_shape`: bell / in / out), zoom/center moves and easing, shared camera moves, alignment, `wb_lock` colour stabilisation, per-shot `stabilize`, transitions, SFX)
- `type/<project>.html`: the title layout and animation, locked to the shot timing (an edit with `"typography": false` renders with no text; the overlay files are kept in case a title comes back)
- `scripts/render.py`: cuts, ramps, zooms, alignment and transitions, then grades, composites the type and encodes
- `scripts/render_type.js`: renders the type layer to transparent PNG frames with Playwright

### Swapping in the original footage
The current renders use WhatsApp copies in `raw/proxy/` (464×832 to 576×1024), AI-upscaled to 1080×1920. To get sharper renders, put the full-resolution phone originals in `raw/originals/`, point `sources` in the edit file at them, and re-run. The cut timings carry over unchanged. HDR (HLG/PQ) iPhone clips are tone-mapped to SDR automatically.
